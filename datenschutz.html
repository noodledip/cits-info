Zugriff und Zweck

Die Anwendung fordert über Google OAuth ausschließlich https://www.googleapis.com/auth/gmail.send an. Diese Berechtigung ermöglicht das Senden von E-Mails im Namen des freigebenden Kontos. Die Software nutzt sie ausschließlich für eigene C-ITS-Briefings an den Betreiber. Sie fordert keine Berechtigungen zum Lesen oder Auflisten bestehender E-Mails und zum Abrufen von Kontakten an.

Für den Versand werden die konfigurierte Absender- und Empfängeradresse sowie selbst erzeugte Briefings aus öffentlichen Quellen verarbeitet.

Speicherung und beteiligte Dienste

Google verarbeitet Autorisierung und E-Mail-Versand. GitHub verarbeitet die Ausführung über GitHub Actions sowie das private Wissensarchiv. Die OAuth-Zugangsdaten werden als verschlüsseltes GitHub Actions Secret hinterlegt und im Versandprozess verwendet. Bei der einmaligen Einrichtung entsteht zusätzlich eine geschützte lokale Übergabedatei außerhalb der Git-Versionierung. Der Betreiber verwaltet und entfernt diese Kopie nach Bedarf.

Das private Repository enthält Briefings, Quellen und Versandnachweise mit Datum, Status und der von Gmail zurückgegebenen Nachrichten-ID. Diese Daten bleiben bis zur Entfernung durch den Betreiber gespeichert. Das Entfernen einer Datei aus dem aktuellen Stand entfernt frühere Git-Versionen nicht automatisch. Bei Fehlern können Diagnoseartefakte für 14 Tage gespeichert werden. GitHub verwaltet Ausführungsprotokolle entsprechend den Repository-Einstellungen.

Nutzung und Weitergabe

Die Anwendung verwendet Google-Nutzerdaten ausschließlich für den beschriebenen Versand und dessen technische Durchführung. Sie verkauft diese Daten nicht und nutzt sie weder für Werbung noch zum Trainieren von KI-Modellen. Die gemeinsame Nutzung der Recherche-Wissensbasis durch Codex und Claude Code umfasst die öffentlich recherchierten Inhalte; OAuth-Zugangsdaten sind davon ausgeschlossen.

Die Nutzung der Google-API-Daten erfolgt gemäß der Google API Services User Data Policy, einschließlich der Limited-Use-Anforderungen.

Widerruf und Entfernung

Die Freigabe kann jederzeit in den Verbindungen des Google-Kontos widerrufen werden. Der Betreiber kann zusätzlich das GitHub Secret entfernen und den Workflow deaktivieren. Bereits versendete E-Mails und gespeicherte Nachweise werden durch den Widerruf nicht automatisch gelöscht. Fragen zur Datenverarbeitung können an die oben genannte Kontaktadresse gerichtet werden.
